# Vioro for Open Source

Eligible, non-commercial open-source projects receive **1 free Deep Audit site subscription** (€169/mo standard value) from [Vioro](https://vioro.io/) in exchange for displaying a static **Security Monitored by Vioro** badge or public link on the monitored project website or documentation.

## What Is Included
- 2-minute uptime and TLS/SSL monitoring
- Daily full-site security scans
- Deep JavaScript bundle and standalone script vulnerability checks + 24/7 instant advisories
- Leaked client-side API key and secret detection
- Security headers, DNS/email posture, and hosting intelligence
- 1-page Executive Security Posture Summary PDF

## Eligibility
- Active project under an OSI-approved license
- Public source repository
- Non-commercial project or documentation website (commercial SaaS, paid plugins/themes, and client agencies are excluded)
- Domain ownership verified in the Vioro dashboard
- Manual review by the Vioro team

## How to Apply
1. Start a cardless 14-day **Deep Audit** trial at [app.vioro.io/signup](https://app.vioro.io/signup) and verify your domain.
2. Add a badge from [vioro.io/open-source/](https://vioro.io/open-source/#badge-kit) (or a public backlink to `https://vioro.io/`).
3. **[Open an OSS Application Issue](https://github.com/cyze-as/vioro-open-source/issues/new?template=oss-application.yml)** (no personal email needed publicly; we match your account via your verified domain).

Not on GitHub (Codeberg, GitLab, or self-hosted)? Copy the email application template at [vioro.io/open-source/#apply](https://vioro.io/open-source/#apply) and send it to `support@vioro.io`.
